Dérivation propre (avant calcul) : avec y_r = x_r + 1 au début du bloc r, la montée de m_r pas impairs
multiplie y par (3/2)^m_r, puis s_r divisions par 2 : y_{r+1} = 3^{m_r} y_r / 2^{m_r+s_r} + (1 − 2^{−s_r}).
Point fixe : y_r = 2^γ · Σ_j b_j A_j (b_j = 1 − 2^{−s_j} ∈ [1/2, 1), A_j produits de suffixes).
Borne basse : terme vide ≥ 1/2. Borne haute : lemme du cycle (rotation où toutes les sommes de suffixes
sont ≤ 0) ⇒ Σ < p. D'où γ − 1 ≤ log₂(x_min + 1) < γ + log₂ p, soit en entiers 2^{K−1} ≤ min_r Y_r < p·2^K.
