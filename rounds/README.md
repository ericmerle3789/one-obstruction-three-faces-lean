# rounds/

The technical half of the Merle–Macindoe correspondence on cycles of the Collatz map,
kept as files rather than only as mail so that it can be read, linked and quoted by line.

One file per round per side, named `R<NN>-<name>.md`. The letter of a round and the
artefacts it argues about live in the same repository, so a claim and its evidence can be
checked together instead of one describing the other.

**Why this exists.** The letters had grown to a length at which they were carrying claims
that only version control can hold honestly: commit hashes, counts of marked statements,
citations of scripts, verification results. Prose makes those expensive to check and
permanent when wrong. A diff makes them cheap and correctable.

**Where the correspondence lives now.** Section 13 of `R11-merle.md` proposed that the
correspondence move into the shared repository (`macindoe/one-obstruction-three-faces`) and
that the two-key rule be expressed as pull-request review. This was adopted: rounds 12
onward are in `rounds/` of the shared repository and enter by pull request, the approving
review being the second key. This folder keeps round 11 as it was sent.

**Standing conventions**, unchanged from `PROTOCOL.md` in the shared repository: every
numbered claim enters via the ledger first; nothing is stated at a grade its evidence
does not carry; corrections are recorded rather than smoothed, and retractions are kept
in place rather than deleted.
